ADR-001: Pipeline Architecture
Date: 27/07/26

Status: Accepted

Context
We need to process data from four sources (CSV, JSON, text, Excel) for Newham Public Library. The data has quality issues and needs to be cleaned before it can be used for analysis.

Decision
We will use a medallion architecture with three layers:

Bronze - raw data ingested exactly as received
Silver - cleaned and validated data
Gold - analysis-ready aggregations

Reasons

Bronze Layer will just be the raw imports of the four data sources. Can always revert if issues arise.
Silver Layer for cleaning the data so it is standardised and any data quality issues are fixed
Gold Layer to be transformed data from silver layer for business ready metrics that can be used for dashboards or business reports
Medallion architecture allows for data lineage and visibility on how data moves and transforms along the pipeline
If more data sources are required, it can be added into bronze without immediately affecting preexisting silver and gold tables

Consequences

Raw data is always preserved in bronze - we can reprocess if cleaning logic changes
Silver is the trust boundary - gold always reads from silver, never bronze
Gold metrics dependent on business requirements on what an analyst would like to use to report on, more metrics can be added for more business metrics
Data quality issues found and addressed in the silver layer rather than in the reports/gold layer
Data stored multiple times in different layers - storage capacity affected
More tests/validation required for each layer
